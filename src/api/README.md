# Environment Setup

This project uses environment variables stored in a `.env` file. The `.env` file is not committed to version control and must be created locally before running the application.

## Setup

### 1. Create a `.env` file

Create a `.env` file in the project root directory (same location as `package.json`).

### 2. Add the required environment variable

```env
API_BASE_URL=http://192.168.0.43:8200/reach
```

### 3. Run the application

Start the project as usual after creating the `.env` file.
